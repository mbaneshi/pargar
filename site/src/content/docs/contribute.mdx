## Pull requests

1. Open or find an issue first, and agree on the approach for anything non-trivial.
2. Branch from **`dev`** (the default branch). `main` only moves on releases.
3. Keep PRs focused, link the issue (`Closes #N`), and get CI green.
4. Every operation is a command: if a human can do it in the UI, an agent must be able to do it through the same command.
5. Never commit a secret. `VITE_*` values are public by design.
6. CI runs on GitHub-hosted runners only.

Read the [seven rules](/pargar/architecture/) first; every review holds changes to them.

## Security

Found a vulnerability? **Don't open a public issue.** Report it privately as described in [`SECURITY.md`](https://github.com/mbaneshi/pargar/blob/dev/SECURITY.md).
