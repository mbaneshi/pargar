# DXF Test Fixtures

Real-world and authored DXF files for round-trip and audit-validator testing. Three oracles run against every file:

1. **vitest round-trip parity** — `packages/file-io/src/__tests__/dxf-fixture-roundtrip.test.ts` (legacy fixtures, per-entity-type assertions).
2. **vitest corpus + structural validation** — `packages/file-io/src/__tests__/dxf-corpus-validation.test.ts` (whole corpus, baseline-pinned re-parse counts, emits `.rt-output/` for the auditor).
3. **`ezdxf audit` in CI** — `.github/workflows/dxf-validate.yml` runs over both the source fixtures and the `.rt-output/` produced by oracle 2.

Layout:

```
test-fixtures/
  ├── *.dxf             — legacy fixtures (provenance uncertain — see below)
  ├── nexus-authored/   — fixtures generated by scripts/build-test-fixtures.ts
  └── jscad/            — vendored from jscad/sample-files (MIT, see jscad/LICENSE)
```

## Legacy fixtures (root)

These were imported into the repo on 2026-04-15 but a previous version of this README claimed `jscad/sample-files` provenance for filenames that don't exist there. **Provenance is being re-verified.** Until each row is confirmed and license-cleared, they are advisory inputs only — they are not used to gate CI.

Header sniffing (the `999 dxfrw 0.6.1` comment in some files) suggests that `blocks1.dxf`, `dimensions.dxf`, and `hatches.dxf` were written by **libdxfrw**, the DXF writer used by LibreCAD (GPLv2). That doesn't necessarily make the resulting *data* GPL-licensed (DXF output is plain data, not derivative of the writer's source), but the task explicitly forbids LibreCAD-sourced fixtures, so these rows are flagged for replacement.

They remain in the corpus today because existing round-trip tests reference them.

## Rules

- Keep individual files under 1 MB. ASCII DXF only (no binary).
- Document license + source for every file. Filename hints are not sufficient — get the upstream URL and commit hash.
- Fixtures are committed to git — they are test inputs, not generated build artifacts.
- Authored fixtures must be byte-deterministic so audit output is reproducible across runs (see `nexus-authored/README.md`).
- Do not add fixtures from LibreCAD (GPLv2), QCAD (GPLv3), or LibreDWG (GPLv3).
