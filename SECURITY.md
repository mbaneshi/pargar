# Security policy

Please **do not** report security problems in public issues, discussions or pull requests.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/mbaneshi/pargar/security/advisories/new)
for this repository. Include what you found, how to reproduce it, and the impact you expect.

You'll get an acknowledgement within a few days. Fixes ship in the next release and the
advisory is published once a fix is available.

## Scope

- The code in this repository (kernel, app, MCP server, Supabase migrations).
- The reference deployment at <https://cad.houshkar.ir>, for issues caused by this code.

Out of scope: findings that need a compromised device, denial of service by traffic volume,
and reports from automated scanners without a working proof.
